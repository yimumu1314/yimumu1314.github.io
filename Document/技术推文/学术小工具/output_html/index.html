安装过程

安装：pip install moffee

在实时 Web 服务器中预览幻灯片或导出为 HTML文件：

moffee live example.md 
moffee make example.md -o output_html/

moffee 其实是一个Python三方模块。所以使用的前提是得有一个Python3的环境。
